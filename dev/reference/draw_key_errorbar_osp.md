# Legend key glyph for [`geom_errorbar_osp()`](https://www.open-systems-pharmacology.org/OSPSuite.Plots/dev/reference/geom_errorbar_osp.md)

Draws a horizontal line with vertical end caps in the legend key,
matching the visual appearance of the rendered error bars.

## Usage

``` r
draw_key_errorbar_osp(data, params, size)
```

## Arguments

- data, params, size:

  Passed from the ggplot2 legend-drawing infrastructure.

## Value

A `grid` grob.
